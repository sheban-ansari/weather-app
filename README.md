#  React Weather App

A modern and responsive Weather Application built using **React.js** and the **OpenWeather API**.  
It provides real-time weather information with dynamic UI changes based on day and night.

---

##  Features

-  Search weather by city name
-  Real-time temperature display
-  Dynamic Day / Night background
-  Smart weather emojis
-  Humidity & Wind Speed details
-  Fully responsive design
-  Secure API key using environment variables

---

##  Tech Stack

- React.js
- JavaScript
- CSS3 (Modern UI + Glassmorphism)
- OpenWeather API
